# Password Cracking – Cybersecurity & Ethical Hacking

## Project Overview

This project focuses on understanding password cracking techniques and evaluating password security through practical, hands-on exercises.

Two approaches were explored to recover the password of a protected PDF file:

- **Module 1:** John the Ripper (JTR) and Johnny GUI.
- **Module 2:** Networkwalks Hash Calculator and Password Cracker.

The exercises demonstrate how password hashes can be extracted from protected PDF files and used in password recovery attacks.

## Module 1 – Password Cracking with John the Ripper (JTR)

**Tools Used:**
- John the Ripper (JTR)
- Johnny GUI
- PDF Hash Extractor
- Windows Notepad

**Tasks Performed:**
1. Downloaded and configured John the Ripper and Johnny GUI.
2. Extracted the password hash from the protected PDF file.
3. Saved the extracted hash in a text file (`hash1.txt`).
4. Imported the hash file into Johnny.
5. Started a password cracking attack.
6. Recovered the PDF password and verified it by opening the protected document.

## Module 2 – Password Cracking with Networkwalks Tools

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser

**Tasks Performed:**
1. Uploaded the protected PDF file to the Networkwalks Hash Calculator.
2. Extracted the PDF password hash.
3. Copied the complete hash value.
4. Submitted the hash to the Networkwalks Password Cracker.
5. Started the password recovery process.
6. Retrieved the recovered password.
7. Verified the password by opening the protected PDF file.

## Key Learning Outcomes

- Understood the fundamentals of password cracking.
- Learned the difference between encryption and hashing.
- Gained practical experience extracting PDF password hashes.
- Explored password recovery using John the Ripper and Johnny GUI.
- Practiced using browser-based password cracking tools.
- Understood the importance of strong passwords and password security.
